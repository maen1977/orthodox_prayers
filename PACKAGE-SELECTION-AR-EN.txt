Safe Windows Cleaner Lite 2.4.0 — اختيار الحزمة / Package selection

العربية
Windows 10/11 ‏64-bit: استخدم Win10-11-x64.
Windows 10/11 ‏32-bit: استخدم Win10-11-x86.
Windows 7 SP1 أو Windows 8 أو Windows 8.1 ‏32/64-bit: استخدم Windows7-8-8.1-Legacy.
تتطلب حزمة Legacy تثبيت ‎.NET Framework 4.6.1 أو إصدار أحدث متوافق مع نظامك.
لا تستخدم الحزمة الحديثة على Windows 7 أو 8 أو 8.1.

English
Windows 10/11 64-bit: use Win10-11-x64.
Windows 10/11 32-bit: use Win10-11-x86.
Windows 7 SP1, Windows 8, or Windows 8.1 32/64-bit: use Windows7-8-8.1-Legacy.
The Legacy package requires .NET Framework 4.6.1 or a later version compatible with your OS.
Do not use the modern package on Windows 7, 8, or 8.1.
