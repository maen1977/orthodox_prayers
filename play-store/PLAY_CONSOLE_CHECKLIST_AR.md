# قائمة تجهيز Google Play — Church Prayers v5.1.0

## جاهز داخل المشروع

- معرّف الحزمة `com.orthodoxprayers.privateapp`.
- `compileSdk` و`targetSdk` على API 36، والحد الأدنى API 26.
- بناء APK/AAB عبر GitHub Actions دون تخزين مفتاح Android في المستودع.
- R8 وتصغير الموارد في Release، ومنع HTTP غير المشفر.
- توقيع مستقل لبيانات اليوم والاحتفاظ بآخر نسخة موثوقة.
- ثلاث قنوات محتوى ديني مستقلة دون ترجمة أو fallback بين اللغات.

## شرط الإصدار الإنتاجي

الإصدار الموقّع محجوب تلقائيًا إلى أن تنجح `scripts/validate_release_readiness.py` وتقارير المقارنة الآلية. يلزم قبل Production:

- اكتمال حزم الخدمات الرسمية للغات الثلاث.
- استيراد مكتبة كتاب مقدس رسمية غير فارغة لكل لغة.
- توفر نص الرسالة والإنجيل الحاليين حرفيًا في اللغات الثلاث.
- نجاح Unit Tests وLint وبناء Debug APK. ويجب أن تنجح اختبارات المحاكي الآلية على API 29 وAPI 35، مع توليد لقطات اللغات الثلاث من نفس البناء.

## أسرار GitHub Environment `production`

- `ANDROID_KEYSTORE_B64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`
- `DATA_SIGNING_PRIVATE_KEY_B64`
- `PLAY_SUPPORT_EMAIL`

بعد اكتمال بوابة المحتوى، أنشئ Tag مطابقًا لرقم النسخة مثل `v5.1.0`. الناتج المتوقع للمتجر هو AAB يحمل رقم النسخة المشتق من Gradle.

## خطوات Play Console

1. أنشئ التطبيق وثبّت معرّف الحزمة قبل أول رفع.
2. فعّل Play App Signing واحفظ مفتاح الرفع ونسخته الاحتياطية بأمان.
3. أدخل بيانات المتجر وسياسة الخصوصية العامة.
4. راجع Data safety من AAB النهائي.
5. ارفع أولًا إلى Internal testing.
6. اختبر اللغات الثلاث، البحث، الصيام، القراءات، الخدمات، الوضع دون إنترنت، والتحديث اليومي.
7. عالج أي crash أو ANR في Pre-launch report؛ أما اختبارات الجهاز ولقطات المتجر فتُنتج آليًا داخل Build.
8. ابدأ بإطلاق تدريجي بعد نجاح بوابات المقارنة الآلية، البناء، اختبار المحاكي، وPre-launch report.

## عناصر يوفّرها المالك

حساب مطور صالح، بريد دعم، رابط خصوصية عام، بيانات المتجر، وإقرار الحقوق والموافقات النهائية.
