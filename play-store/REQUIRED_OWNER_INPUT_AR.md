# معلومات وإجراءات خارجية يكمّلها مالك حساب النشر

أتمتة R40 تنفّذ المقارنة الدينية التقنية، فحص المصادر، الاختبارات، بناء APK/AAB، اختبار المحاكي، إنشاء لقطات المتجر، وفحص حزمة Google Play دون مراجعة بشرية للمحتوى اليومي.

تبقى فقط عناصر لا يستطيع المستودع إنشاؤها قانونيًا أو الوصول إليها بدل مالك الحساب:

1. بريد دعم عام فعلي، ويُحفظ في GitHub Secret باسم `PLAY_SUPPORT_EMAIL`.
2. تفعيل GitHub Pages من `main` والمجلد `/docs` وفحص رابط الخصوصية المنشور.
3. تعبئة إجابات Play Console الخاصة بالحساب: Data safety، الجمهور، Content rating، وإقرارات الحقوق.
4. التأكد من امتلاك حق توزيع أي حزم نصية خارجية تُضاف مستقبلًا؛ الأتمتة تمنع النشر عند غياب بيانات المصدر والبصمة، لكنها لا تستطيع منح ترخيص قانوني.
5. حفظ مفاتيح Android ومفتاح توقيع البيانات خارج المستودع، وإضافتها إلى GitHub Secrets فقط.
6. بدء مسار الاختبار الداخلي أو المغلق من حساب Play Console وفق ما يفرضه الحساب.

لا ترفع أي ملف JKS أو PEM خاص أو كلمات مرور أو مستندات موافقات خاصة إلى المستودع العام.

> لقطات الشاشة العربية والإنجليزية واليونانية تُولّد آليًا من محاكي Android في GitHub Actions، ولا تحتاج إدخالًا يدويًا.
