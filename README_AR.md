# Church Prayers

تطبيق صلوات أرثوذكسي خفيف يعمل على Android 8.0 فأحدث، باللغات العربية والإنجليزية واليونانية.

## البناء على GitHub

يوجد مسار واحد فقط باسم **Church Prayers**.

1. افتح تبويب **Actions**.
2. اختر **Church Prayers**.
3. اضغط **Run workflow**.
4. بعد النجاح نزّل الملف الوحيد باسم **Church-Prayers**.

داخله ملفان فقط:

- `Church-Prayers.apk` للتثبيت على الهاتف.
- `Church-Prayers.aab` للرفع إلى Google Play.

تعمل فحوص المحتوى واللغات والأمان والروزنامة داخليًا داخل نفس المهمة، دون مسارات أو حزم إضافية.

## التحديث اليومي المحلي

- يعمل من داخل APK نفسه باستخدام `LocalDailyContentEngine`.
- يغطي التقويم المضمّن السنوات 2026–2050 ونافذة من 9 أيام.
- لا يوجد `.github/workflows/update.yml` في هذا الإصدار.
- Workflow GitHub المتبقي اختياري لبناء APK/AAB ونشر نسخة تطبيق جديدة فقط.

## التوافق

- الحد الأدنى: Android 8.0 / API 26.
- الهدف: Android API 36.
- الروزنامة الداخلية محمية حتى نهاية سنة 2050.

## قداس اليوم الكامل والمتابعة أثناء الخدمة

يعرض التطبيق **قداس اليوم الكامل** مع القراءات والترانيم المتغيّرة من المحرك اليومي المحلي والتقويم والنصوص المضمّنة، وفق العقد الموجود في `canonical/follow_along_liturgy_contract.json`.

- يجهّز التطبيق اليوم محليًا عند **00:03** بتوقيت عمّان، ويعيد الفحص عند فتح التطبيق؛ لا يحتاج Daily Update إلى GitHub Actions أو الإنترنت.
- العربية والإنجليزية واليونانية قنوات أصلية مستقلة؛ **لا توجد ترجمة بين القنوات**.
- فحص سلامة نص قداس القديس يوحنا الذهبي الفم يمنع كلمات OCR المكسورة واختلاط اللغات وترتيب الأنافورا غير الصحيح.

## خدمة كنسية

داخل قسم **الصلوات** توجد بطاقة **خدمة كنسية**. تفتح قائمة خدمات طقسية ثابتة تشمل العماد والميرون، القداس والمناولة، الاعتراف، الخطوبة والزواج، حل الأكاليل، زيارة المرضى وسر الزيت المقدس، الجناز، النياحة والذكرانيات، تكريس المنازل، الرسامة الكهنوتية، تقديس المياه الكبرى، وخدمة الساعات.

القراءات الثابتة الموثقة تُعرض من الكتاب المقدس المضمّن داخل التطبيق باللغة المختارة نفسها. لا توجد ترجمة آلية بين العربية والإنجليزية واليونانية، ولا يتم ملء نص طقسي كامل من لغة أخرى عند غياب مصدر كنسي أصلي مجاز.
