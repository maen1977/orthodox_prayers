# الصلوات الكنسية — تطبيق خفيف لمتابعة القداس

تطبيق أندرويد أرثوذكسي للمؤمن العادي، لا مكتبة ضخمة من الكتب. الصفحة الرئيسية تقود مباشرة إلى:

- قداس اليوم الكامل في صفحة واحدة متسلسلة.
- القراءات اليومية.
- الصلوات اليومية الأساسية.
- البث المباشر.
- الإعدادات.

## نموذج المحتوى

نص القداس الثابت محفوظ مرة واحدة فقط. ملف اليوم صغير ويحتوي القطع المتغيرة وحدها، مثل:

- إنجيل السَحَر قبل القداس، عندما ينشره مصدر رسمي معتمد.
- طروباريات اليوم والقنداق.
- البروكيمنن والرسالة والإنجيل.
- آية المناولة والقطع الخاصة بالمناسبة عند توفرها.

يركّب التطبيق هذه القطع في مواضعها داخل النص الثابت بعد التحقق من المصدر والتوقيع. غياب قطعة يومية لا يكرر القداس ولا يعطله؛ تُحجب القطعة غير المتوفرة ويبقى النص الثابت صالحًا للقراءة.

قارئ القداس يعرض مراحل الدخول الصغير والدورة الكبرى والأنافورا والمناولة والختام، مع قفز سريع بين المراحل. ويبرز ما يقوله الكاهن سراً وما يقوله المؤمن سراً فقط عندما تنص النسخة الأصلية في اللغة المختارة على ذلك. صلوات الاستعداد للمناولة والشكر بعدها تُضم إلى الصفحة نفسها عندما تكون نسختها الأصلية المعتمدة متوفرة في حزمة تلك اللغة.

العقد التنفيذي لهذا النطاق موجود في:

`canonical/follow_along_liturgy_contract.json`

## اللغات

العربية والإنجليزية واليونانية ثلاث قنوات مستقلة:

- العربية: مطرانية الروم الأرثوذكس في الأردن وبطريركية القدس العربية.
- الإنجليزية: بطريركية القدس الإنجليزية ومصادر يونانية أرثوذكسية إنجليزية معتمدة.
- اليونانية: بطريركية القدس والكنيسة اليونانية والمصادر اليونانية الأرثوذكسية المعتمدة.

لا توجد ترجمة بين القنوات، ولا ترجمة آلية، ولا إعادة صياغة بالذكاء الاصطناعي، ولا تشكيل أو نبرات آلية. إذا غاب النص الأصلي المعتمد للغة المختارة يظهر أنه غير متوفر، ولا يُنسخ نص لغة أخرى مكانه.

## التحديث والنافذة المتحركة

ينشر النظام حزمة موقعة متحركة بدل ملف يوم واحد أو أسبوع ثابت:

- الإعداد الافتراضي: `21` يومًا متتاليًا ابتداءً من تاريخ الأردن الحالي.
- الحد الأدنى: `9` أيام.
- الحد الأعلى: `42` يومًا.
- في كل تشغيل تُزاح النافذة تلقائيًا، فيدخل يوم جديد وتُحذف الأيام التي انتهت.
- لا يوجد تحميل سنوي ثابت ولا تواريخ مكتوبة يدويًا داخل Workflow.
- تُستخرج مراجع الرسالة والإنجيل من سجل الأردن القانوني، ثم يُجلب النص العربي والإنجليزي واليوناني من corpus مستقل مسجل لكل لغة، دون ترجمة آلية.

يعمل GitHub Actions ثلاث مرات بتوقيت `Asia/Amman`: `00:07` و`00:37` و`06:37`. ويستطيع التشغيل اليدوي تغيير المدى عبر `window_days` من 9 إلى 42. يجري فحص المصادر الخارجية مرة واحدة لكل تشغيل، ثم تُبنى الأيام المقبلة محليًا من العقود والنصوص الموثقة لتفادي تكرار الاتصالات وإطالة زمن البناء.

داخل التطبيق يستمر WorkManager في الفحص عند `01:00` و`06:00`، ويختار يوم الجهاز الصحيح من الحزمة الموقعة. عند غياب الشبكة تبقى آخر حزمة سليمة والنسخة المضمنة الموقعة متاحتين.

كل حزمة تحمل توقيع RSA ورقم مراجعة متزايد وبيانات تغطية البداية والنهاية وعدد الأيام. يقبل التطبيق عقد الترقية القديم مؤقتًا، ويعتمد عقد النافذة المتحركة الجديد للإصدارات اللاحقة.

## حماية النص

- نص العرض محفوظ بمحارفه الأصلية.
- كل قناة لغة موقعة منفصلة.
- لا تظهر قراءات يوم سابق باسم اليوم.
- مواضع اليوم غير الموثقة تُحجب بدل ملئها بتخمين.
- رموز التشخيص والبصمات وتفاصيل المصادر مخفية افتراضيًا داخل الإعدادات المتقدمة.
- لا إعلانات، ولا تسجيل دخول، ولا تتبع، ولا مفاتيح خاصة داخل التطبيق.

## الفحص المحلي

```bash
python -m pip install -r requirements-dev.txt
python scripts/run_quality_gate.py --strict-native-lanes
```

فحص النطاق الخفيف مباشرة:

```bash
python scripts/validate_follow_along_liturgy.py
```

إنشاء مشروع كامل نظيف دون `.git` أو ملفات البناء أو المفاتيح:

```bash
python scripts/create_clean_source_archive.py \
  ../OrthodoxPrayers-5.0.17-follow-along-FULL.zip \
  --root-layout
```
