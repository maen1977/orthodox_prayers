# Safe Windows Cleaner Lite 2.4.0

برنامج صيانة وتنظيف خفيف، ثنائي اللغة، ومخصص للأجهزة الضعيفة. لا يثبت خدمة دائمة في الخلفية، ولا يستخدم تنظيف RAM وهميًا، ولا ينفذ تنظيف Registry شاملًا.

## حزم التشغيل

| النظام | الملف المناسب | التقنية |
|---|---|---|
| Windows 10/11 ‏64-bit | `SafeWindowsCleaner-2.4.0-Win10-11-x64-Setup.exe` | .NET 8 Self-contained |
| Windows 10/11 ‏32-bit | `SafeWindowsCleaner-2.4.0-Win10-11-x86-Setup.exe` | .NET 8 Self-contained |
| Windows 7 SP1 / 8 / 8.1 ‏32/64-bit | `SafeWindowsCleaner-2.4.0-Windows7-8-8.1-Legacy-Setup.exe` | ‎.NET Framework 4.6.1 أو أحدث |

الحزمتان الحديثتان لا تحتاجان إلى تثبيت .NET يدويًا. حزمة Windows 7/8/8.1 تحتاج إلى **Windows 7 SP1 أو Windows 8 أو Windows 8.1، مع ‎.NET Framework 4.6.1 أو إصدار أحدث متوافق**، وتعرض رسالة واضحة إذا كان المتطلب ناقصًا.

> Windows 7 وWindows 8 وWindows 8.1 خارج الدعم الأمني من Microsoft. نسخة Legacy مخصصة للتوافق فقط، وميزاتها أقل عمدًا من نسخة Windows 10/11.

## وظائف النسخة الحديثة

- تنظيف الملفات المؤقتة والكاش بعد المعاينة.
- إزالة برنامج محدد باستخدام أداة الإزالة الرسمية ثم فحص البقايا المؤكدة.
- عرض التطبيقات الثقيلة وإغلاق تطبيق يختاره المستخدم.
- الحجر والاستعادة.
- إصلاح عناصر بدء التشغيل المكسورة.
- ذاكرة افتراضية قابلة للاستعادة بحجم 4 أو 8 أو 16 غيغابايت وفق مساحة القرص، مع إبقاء 8 غيغابايت حرة لويندوز.
- معلومات ذاكرة كرت الشاشة دون الادعاء أن القرص يتحول إلى VRAM.
- العربية والإنجليزية فقط، مع إعادة تشغيل الواجهة عند تغيير اللغة لمنع خلط النصوص.

## نسخة Windows Legacy

تحتوي على الواجهة الخفيفة فقط:

- تنظيف مؤقت آمن.
- إزالة البرامج الرسمية.
- التطبيقات الثقيلة والإغلاق اليدوي.
- الحجر والاستعادة.
- الذاكرة الافتراضية المتدرجة 4/8/16 غيغابايت.
- إعدادات عربية أو إنجليزية منفصلة.

لا تحتوي على محركات Windows الحديثة أو أدوات GPU المتقدمة أو خدمة خلفية.

## التثبيت والترقية والإزالة

- جميع ملفات Setup والتطبيقات تطلب صلاحية Administrator.
- تستخدم الحزم الثلاث **هوية تطبيق واحدة** ومجلد تثبيت واحدًا؛ تثبيت الحزمة الصحيحة يستبدل النسخة القديمة بدل إنشاء نسخة ثانية.
- يغلق Setup العملية القديمة ويحذف الملفات الباقية في مجلد التطبيق قبل النسخ.
- تشغيل التطبيق بعد التثبيت يستخدم صلاحية Setup المرتفعة، ما يمنع خطأ `CreateProcess failed; code 740`.
- الإزالة تستعيد إعداد الذاكرة الافتراضية المحفوظ إن وجد، ثم تحذف ملفات التطبيق والبيانات والمهمة المجدولة.

## اللغة ووحدات الحجم

العربية تعرض: `بايت / كيلوبايت / ميغابايت / غيغابايت`.

English displays: `B / KB / MB / GB`.

بوابة الإصدار ترفض اللغات غير المكتملة، والأسماء المختلطة في قائمة Settings، ووحدات الأحجام التابعة للغة الأخرى.

## البناء

```powershell
./scripts/validate-release.ps1
./build-windows.ps1 -GitHubRepository "OWNER/REPOSITORY"
```

بوابة المصدر متعددة المنصات:

```bash
python scripts/static-validate.py
```
