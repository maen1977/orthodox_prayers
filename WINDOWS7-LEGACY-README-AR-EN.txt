Safe Windows Cleaner Lite 2.4.0 — Windows Legacy

العربية
هذه الحزمة مخصصة لـWindows 7 SP1 وWindows 8 وWindows 8.1 بنواتي 32 و64 بت.
تحتاج إلى ‎.NET Framework 4.6.1 أو إصدار أحدث متوافق مع نظامك، ثم إعادة تشغيل Windows بعد تثبيته.
هذه الأنظمة خارج الدعم الأمني الحالي من Microsoft؛ استخدم نسخة Legacy للتوافق فقط.
الميزات مقصودة أن تكون خفيفة: تنظيف آمن، إزالة البرامج الرسمية، التطبيقات الثقيلة، الاستعادة، والذاكرة الافتراضية.

English
This package is for Windows 7 SP1, Windows 8, and Windows 8.1, 32-bit or 64-bit.
It requires .NET Framework 4.6.1 or a later version compatible with the OS, followed by a Windows restart after installation.
These operating systems are outside current Microsoft security support; use the Legacy edition for compatibility only.
The feature set is intentionally light: safe cleanup, official uninstallers, heavy-app view, restore, and virtual memory.
