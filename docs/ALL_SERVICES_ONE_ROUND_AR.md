# استكمال الخدمات الخمس عشرة في جولة ذرّية واحدة

## النتيجة الحالية

أصبح المشروع يملك مسارًا واحدًا لاستكمال الخدمات الخمس عشرة بالعربية والإنجليزية واليونانية، بإجمالي 45 مسارًا لغويًا.

- المسارات المثبتة حاليًا: 4 من 45.
- المسارات التي تحتاج ملفات مصدر أصلية ومراجعة: 41 من 45.
- لا يُعدّل التطبيق أثناء التحضير.
- لا تُرقّى خدمة منفردة إلى الإنتاج.
- إما أن تنجح الحزمة كلها، أو يبقى المشروع الحالي من دون تغيير.

## الخدمات المشمولة

1. الغروب.
2. النوم الصغرى.
3. نصف الليل.
4. السحر.
5. الساعة الأولى.
6. الساعة الثالثة.
7. الساعة السادسة.
8. الساعة التاسعة.
9. التيبيكا.
10. الذبيحة الإلهية أو التقدمة.
11. قداس القديس يوحنا الذهبي الفم.
12. قداس القديس باسيليوس الكبير.
13. قداس السابق تقديسه.
14. صلوات ما قبل المناولة.
15. صلوات الشكر بعد المناولة.

## طريقة الاستخدام

1. انسخ `canonical/all_services_source_bundle.template.json` إلى:
   `private_sources/all_services_v1/manifest.json`.
2. ضع الملفات الأصلية المصرح باستخدامها داخل المجلد نفسه.
3. أكمل بيانات المصدر والبصمة والإذن في ملف `manifest.json`.
4. شغّل:

```bash
python scripts/prepare_all_services_completion_round.py --require-complete
```

5. راجع ملفات المقارنة فقرة بفقرة، من دون ترجمة أو إعادة صياغة.
6. بعد اعتماد جميع ملفات المراجعة شغّل:

```bash
python scripts/promote_all_services_completion_round.py \
  --reviewed-root private_sources/all_services_v1/reviewed \
  --output-project ../orthodox_prayers_completed
```

7. شغّل بوابة الإنتاج:

```bash
python scripts/validate_all_services_completion_round.py --production
```

## قواعد الحماية

- الترجمة الآلية للنصوص الليتورجية ممنوعة.
- إعادة الصياغة أو التصحيح بالذكاء الاصطناعي ممنوعان.
- مخرجات OCR لا تُنشر تلقائيًا.
- كل فقرة منظمة يجب أن ترتبط بفقرة من ملف المصدر الأصلي.
- ملفات المصادر الخاصة مستثناة من Git بواسطة `.gitignore`.
- باسيليوس والسابق تقديسه يحتويان فتحات منظمة للقراءات والقطع اليومية المتغيرة بدل الملاحظات المؤقتة.
- بوابة الإصدار الموقّع ترفض النشر ما لم تصبح النتيجة 45 من 45.

## الحالة الصادقة

هذه المرحلة أكملت نظام الاستيراد والترقية الذرّية، ولم تخترع النصوص الناقصة. لا يمكن الوصول الصادق إلى 45 من 45 قبل توفير ملفات المصادر الأصلية المصرح بها ومراجعتها فقرةً فقرةً.
