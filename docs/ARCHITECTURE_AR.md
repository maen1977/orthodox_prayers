# بنية التطبيق 5.6.4

## المبدأ العام

التطبيق يعمل Offline أولًا على Android 8.0 / API 26 فأحدث. العربية والإنجليزية واليونانية ثلاث قنوات نصية مستقلة؛ لا يترجم التطبيق النصوص الدينية آليًا بين اللغات ولا يستخدم لغة بديلة عند غياب النص المطلوب.

## المحتوى اليومي

- `LocalDailyContentEngine` يجهّز عرض اليوم من البيانات المضمّنة داخل APK، مع تقويم 2026–2050.
- التحديث المحلي المجدول يكون عند 00:03 بتوقيت `Asia/Amman`، ويعاد التحقق عند فتح التطبيق.
- لا يوجد Daily Update شبكي ولا `.github/workflows/update.yml`.
- القراءات تُحل من مكتبات الكتاب المقدس الأصلية المضمّنة لنفس اللغة، مع فحوص تمنع الخلط بين العربية والإنجليزية واليونانية.

## طبقات البيانات

- `data/scripture/native/<lang>`: مصادر/بيانات الكتاب المقدس الأصلية وبيانات الـmanifest لكل لغة.
- `app/src/main/assets/data/scripture`: النسخة المضمّنة داخل التطبيق.
- `data/services/native` وبيانات الخدمات المولّدة: مصادر الخدمات الكنسية المسموح بإعادة توزيعها.
- `data/directory/churches.json`: snapshot مصدر لدليل الكنائس المدقّق، ويُزامن مع `app/src/main/assets/data/churches.json`.
- `canonical/`: العقود، الأقفال، وسياسات المصدر التي تعتمد عليها بوابات الجودة.

## التطبيق

- `OrthodoxPrayersApp`: يهيّئ مستودع البيانات وخدمات التطبيق.
- `DataRepository`: يقرأ البيانات المضمّنة ويعرض بيانات اللغة المختارة فقط.
- `LocalDailyContentEngine`: يركّب محتوى اليوم محليًا من التقويم والقراءات والخدمات.
- `ReaderScreen`: يعرض النصوص والخدمات والقداس المتصل.
- `SearchEngine`: يبحث في النصوص، الكنائس، وروابط الخدمات الرسمية دون تغيير النص الأصلي.

## GitHub Actions

يوجد Workflow حالي واحد فقط: `.github/workflows/church-prayers.yml` باسم **Build Church Prayers Fast**.

يقوم بالآتي:

1. يحصد بيانات المصادر الرسمية اللازمة لمرحلة البناء ويعيد استخدام الكاش المسموح.
2. يجهّز بيانات 2026–2050 ومصادر الكتاب المقدس والخدمات المطلوبة.
3. يشغّل `scripts/run_local_daily_release_gate.py` وفحوص التغطية الصارمة.
4. يجهّز Java/Gradle ثم يشغّل Unit Tests و`lintRelease` ويبني Debug APK وRelease APK وAAB.
5. يرفع حزمة `Church-Prayers`، ويمكنه نشر GitHub Release موقّع عند توفر أسرار التوقيع المطلوبة.

الـworkflows التاريخية `build.yml` و`update.yml` و`play-internal.yml` و`weekly-health.yml` ليست جزءًا من البنية الحالية. أدوات المحاكي، اختبار الترقية، قياس الأداء، وتأهيل الإصدار ما زالت موجودة كسكربتات مستقلة ويمكن تشغيلها عند الحاجة، لكنها ليست Jobs منفصلة في المسار السريع الحالي.

## حماية الانحدار

- قفل التقويم 2026–2050 يتحقق منه `validate_calendar_immutability.py`.
- manifests الكتاب المقدس تُفحص مقابل الاستخراج الحالي لمنع drift بين المصدر والـassets.
- مولّد دليل الكنائس يحتفظ بأكبر snapshot رسمي مدقّق عند العمل Offline، ولا يسمح لنتيجة شبكة ناقصة بشكل كبير أن تستبدل الدليل الكامل تلقائيًا.
- بوابات المحتوى تمنع خلط اللغات، النصوص الدينية الوهمية، وادعاء اكتمال خدمة عندما لا يثبت المصدر ذلك.
