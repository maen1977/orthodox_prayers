# المرحلة الرابعة: دليل الطبعات الكاملة

أضيفت بوابة مستقلة تربط كل خدمة توصف بأنها `complete_exact_native_edition` بنصها المعبأ فعلياً ومصدرها الأصلي وبصمة المحتوى وبنية إلزامية.

## ما أُغلق في هذه المرحلة

- القداس الإلهي للقديس يوحنا الذهبي الفم بالإنجليزية: طبعة أصلية كاملة مثبتة.
- القداس الإلهي للقديس يوحنا الذهبي الفم باليونانية: طبعة أصلية كاملة مثبتة.
- صلوات ما قبل المناولة العربية: بقيت مثبتة كخدمة كاملة.
- صلوات الشكر بعد المناولة العربية: بقيت مثبتة كخدمة كاملة.

## ما بقي محجوباً

القداس العربي الحالي لا يرقى إلى الطبعة الكاملة: هو أقصر بصورة مادية، وبعض الأفاشين والأقسام الثابتة مضغوطة أو غير مفصولة. لذلك لم تتم ترقيته. جميع الخدمات الأخرى تبقى بحالتها الصادقة حتى استيراد ملف مصدر أصلي كامل لكل لغة.

## قاعدة النشر

وجود رابط رسمي أو امتلاء حقول JSON لا يكفي. الترقية تتطلب ملف طبعة أصلية واحداً، بصمة ثابتة، حدّاً أدنى للحجم والبنية، وفحصاً يمنع النصوص المؤقتة والترجمة الآلية.
